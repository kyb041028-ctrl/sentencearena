# 후보 초안. 공식 STATE와 CHANGELOG가 아님

이 파일은 10–13차 작업을 적기 위한 초안이다. docs/SENTENCEARENA_STATE.md 와 CHANGELOG를 수정하지 않았다. 실DB에 넣지 않은 작업은 COMPLETE가 아니다.

## STATE에 나중에 옮길 문장

민감정보 철회 함수, 계산 저장 시점의 동의 재확인, 반응 스냅샷 재확인은 후보 SQL이다. 운영 데이터베이스에 적용하지 않았고 실DB 검증이 없다.

서버를 이 후보대로 배포하면 withdraw_sensitive_political_consent RPC가 없는 데이터베이스에서 철회는 실패한다. 권한 SQL은 권한만 추가한다. 그 파일만으로 철회 경합이 닫히지 않는다.

감사 사용자 번호 NULL SQL과 service_role 최소 권한 SQL은 sentencearena-dev에서만 확인된 기록이다. Production 적용 기록은 아니다.

법률 공개 문안은 초안이다. 사업자 정보와 시행일이 비어 있다.

## CHANGELOG에 나중에 옮길 문장

후보. 미적용.

- 철회를 한 트랜잭션 함수로 두는 SQL 후보를 추가했다.
- 계산 함수 후보가 성향 행을 쓰기 전에 분리 동의를 사용자 번호 순으로 잠그고 다시 확인한다. 점수식과 상한 500은 현재 함수와 같다.
- 반응 함수 후보가 새 점수와 영토 복사만 동의가 있을 때 남긴다. 좋아요와 싫어요 개수와 옛 반응은 유지한다.
- 삭제된 계정에 대한 늦은 동의 저장을, 인증 조회가 가능한 서버에서 거절한다.
- 운영 SQL 목록 검사는 등록 파일 누락과 목록 밖 파일을 구분한다. 후보를 REQUIRED로 올리지 않았다.

완료로 적지 말 것: Production 적용, 실DB 검증, 법률 문안 공개, NAVER 재시작.
