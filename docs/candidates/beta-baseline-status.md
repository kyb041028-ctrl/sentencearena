# 4차 베타 통합 후보 상태 메모

이 파일은 후보 메모입니다. PRODUCTION COMPLETE 가 아닙니다. 공식 기준본이 아닙니다. 16차 로컬 커밋에서 STATE의 기존 완료 표시는 바꾸지 않았고, 모바일은 보류 메모만 추가했습니다.

## 유지

- 첫 시민 안내와 첫 방문 안내 연결. 퀘스트 스크립트가 있으면 옛 안내 창을 같이 열지 않습니다.
- 질문 12개, 지원 메일, 세션 조회 실패 후 재시도, 성향 삭제 오류 시 동의 행을 비우기 전에 실패.
- 감사 보상 계획 파일은 서버가 호출하지 않습니다.

## 제외

- sentencearena-agent-legal-pages 의 약관 덮어쓰기, 첫 화면 링크, 가입 화면 링크.
- 원래 폴더의 미기록 가입 동의 문구. 메일을 철회 창구처럼 두고, 성향 기능을 가입 필수라는 새 문장으로 넓힙니다.
- 정치 동의 실험의 서버 파일과 SQL, 로그인 복구의 auth.js, 프로필 V2, 게시판 가드 SQL, 게시판 시각 실험.

## 보류

- 모바일: 임시 호환 대응 완료. 정식 모바일 최적화 보류. 390px에서 본문 약 5px 가독성 문제가 남음. 운영 적용이 아님. 모바일 최적화를 완료로 적지 않음.
- 사업자 번호, 주소, 대표자, 공개 연락처, 개인정보 담당자, 시행일.
- 개척·수호를 철회 때 중앙으로 바꿀지, 반응 사본을 지울지.
- 두 SQL의 운영 적용. 감사 보상 계획을 신고 처리에 연결할지.

## GitHub STATE 완료 표시와 이 후보 코드의 차이

16차 전에는 STATE를 고치지 않았습니다. 16차에서는 기존 완료 표시를 유지하고, 모바일 보류 메모만 추가했습니다.

1. 계정 탈퇴는 완료로 적혀 있고, 같은 STATE는 감사 트리거가 운영에 없어 감사 이력이 있는 탈퇴가 실패할 수 있다고 적습니다. 이 후보는 SQL을 적용하지 않았습니다.
2. 동의 철회가 성향 상태와 이력을 지운다고 적혀 있습니다. 이 후보 코드는 삭제 오류 시 동의 행을 비우기 전에 멈추지만, 트랜잭션이 아니고 반응 사본과 프로필 영토와 Daily Issue와 브라우저 저장이 남을 수 있습니다.
3. 신고 처리 완료와 별도로, 제재와 감사, 거절과 감사의 한 트랜잭션은 Deferred입니다. 보상 계획은 그 공백을 닫지 않습니다.
4. 첫 방문 안내는 구현으로 적혀 있습니다. 이 후보는 퀘스트가 로드되면 그 안내를 퀘스트로 넘깁니다. 퀘스트 자체는 STATE의 완료 항목이 아닙니다.
5. 2026-10-25 기준 오픈베타 코드 블로커는 Launch Finalization만 남았다고 적습니다. 법률 문서 확정, 사업자 정보, 운영 DB 적용, 실브라우저 검증은 아직입니다.
6. 스케줄러 네 개의 정책 완료와 2026-09-06 legal_hold 운영 완료는 이 후보가 다시 확인한 가동 사실이 아닙니다. 2026-10-14 프로세스 정지 기록은 STATE에 이미 있습니다.

## 공식 기준본이 되려면 아직 필요한 순서

1. 이 후보의 파일 범위를 사용자가 승인한 뒤 commit.
2. 그 commit을 master에 합치는 별도 승인. 원본 폴더의 미기록 약관 문구와 섞지 않습니다.
3. 감사 트리거와 서비스 권한 SQL의 운영 적용 별도 승인. 적용 전 함수 본문과 권한 목록 저장. 이 메모가 적용 순서를 확정하지는 않습니다.
4. 운영 또는 승인된 실환경에서 로그인, 가입, 첫 시민 안내, 동의 철회, 탈퇴, 신고, 권리침해를 다시 확인. 그 전에는 운영 검증 완료가 아닙니다.
