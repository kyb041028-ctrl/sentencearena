## 미완료와 이유

- 작업 폴더의 문서 수정 및 로그인/앱 footer 연결 패치는 자동 승인 검토가 두 번 시간 초과되어 실행하지 못했다. 위험 판정으로 거절된 것이 아니며, 사용자 승인 철회도 아니다.
- 실제 브라우저 렌더링은 확인하지 않았다. HTML 정적 검사가 브라우저에서의 잘림·글자 겹침 검증을 대신하지 않는다.
- 운영자/개인정보 담당자 공개 정보는 사용자에게 한 번에 질문했으며 미정으로 유지한다. 임의 이름·주소·연락처를 만들지 않는다.
- 문서 검토본을 확정 약관 또는 법률 검토 완료본으로 공개하지 않는다.

원격 업로드·commit·push·merge·운영 DB 변경·서버 시작·배포 없음. 기존 사용자 작업은 정리하거나 덮어쓰지 않았다.
