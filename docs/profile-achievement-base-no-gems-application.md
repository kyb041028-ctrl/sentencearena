## 로컬 Cursor 적용
1. 이 브랜치에서 **기본판 PNG 파일 하나만** 현재 로컬 작업 트리의 `public/assets/profile-achievement-slots/` 아래로 복사한다. 기존 미커밋 코드를 덮거나 브랜치를 통째 병합하지 않는다.
2. 현재 페이지의 **'대표 업적' 영역에 기본판을 1회만 표시**하고, 그 위에 별도로 렌더링 중인 빈 업적 프레임 3개를 그대로 유지한다. 기본판에 슬롯 프레임을 합성해 두지 않는다.
3. **기본판과 슬롯 3개를 하나의 공통 컨테이너에서 같이 왼쪽으로 이동**한다. PC 최초 조정값은 현재 위치 대비 -16px으로 시작하며, 실제 DOM bounding box 측정에 따라 보정한다. 한 요소만 이동하면 안 된다.
4. `영토 기록` 블록 시작선과 기본판 우측 가장자리 사이 최소 12px의 여유, 왼쪽 프로필 장식과 기본판 사이 최소 8px의 여유를 유지한다. 실제 화면이 좁아 두 조건이 동시에 불가능하면 임의로 크기를 왜곡하지 말고 배치 제약을 보고한다.
5. 빈 슬롯과 완성 업적은 **동일 프레임 영역에서 93×71px 비율 및 동일 CSS 크기**로 교체한다. 별도 희귀도 테두리 중복 사용 금지. 테두리 크기 왜곡 금지.
6. KR/US 전체 스킨, PC/모바일의 0·1·3개 상태를 캡처하고, 영토 기록과의 겹침이 없는지 확인한다. 새 프레임이나 보석 생성 금지.
7. commit, push, master/운영 DB/배포 금지.
