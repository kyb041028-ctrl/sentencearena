# 업적 기본판: 중립 양피지색 최종 교체 및 균형 배치

## 자산
- `achievement_base_parchment_gold_342x88.png`: 342×88 PNG, 따뜻한 아이보리·양피지색, 금색 가장자리 장식, 보석 없음.
- 과거 파란색 `achievement_base_no_gems_342x88.png`는 사용하지 말 것.
- 이 자산 브랜치만 별도 사용. 현재 개발 브랜치에 병합하지 말 것.

## 실제 화면 레이아웃 필수 수정
1. 기존 대표 업적의 기본판과 빈 업적 테두리 세 개를 **하나의 공통 컨테이너**에서 배치한다.
2. 좌측 기준: 대표 업적 내용 영역의 실제 왼쪽 경계. 우측 기준: '영토 기록' 앞 세로 구분선의 실제 왼쪽 경계.
3. 두 경계 사이에서 패널을 **수평 중앙 정렬**, 좌우 시각 여백 차이 **2 CSS px 이하**가 목표다. 이전 `left: -16px` 같은 절대 이동값에 의존하지 않는다.
4. PC/모바일 가용 폭에 맞춰 패널과 업적 슬롯 3개를 **동일 비율로 함께 축소**한다. 원본 파일의 342:88, 93:71 비율 및 슬롯 오프셋(16, 124, 232)을 유지하되 CSS 표시 너비는 가변으로 한다. 모든 빈 슬롯과 획득 이미지 표시 크기 완전 동일.
5. 양쪽 최소 여백 목표 8px(가능하면 10~12px); 장식, 세로 바, 영토 기록 텍스트와 겹치지 않도록 한다.
6. 프레임 3개는 별도 레이어이다. 기본판에 프레임을 새기거나 이중으로 출력하지 않는다. 기존 그림 4종은 수정 금지.
7. KR/US, 진보·중앙·보수·외계, PC/모바일 각각 계산된 leftGap/rightGap을 수치로 기록하고 실제 화면 비교 캡처를 남긴다.
8. 기존 미커밋 변경, 선거/계급/게시판/업적 조건을 보존. 운영 DB, 배포, master, commit, push 금지.
