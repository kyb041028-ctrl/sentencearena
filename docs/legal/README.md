# 법적·운영 문서 검토용 초안

이 폴더의 문서는 **베타 공개 전 내부 검토용 초안**입니다.

- 사이트 화면에 연결하지 않았습니다.
- 가입 흐름, 체크박스, Production, 데이터 저장구조는 변경하지 않았습니다.
- 사업자 명칭, 대표자, 주소, 지원 이메일, 개인정보 담당자, 시행일은 비워 두었고, 표기는 `Launch Finalization에서 확정`입니다.
- 소셜 로그인 코드 확인과 오픈 직전 Production 체크리스트는 공개 개인정보 항목표가 아닙니다.

파일:

- `TERMS_DRAFT.md` — 이용약관 초안
- `PRIVACY_POLICY_DRAFT.md` — 개인정보처리방침 초안
- `COMMUNITY_POLICY_DRAFT.md` — 운영정책 초안
- `BETA_LEGAL_OPEN_ITEMS.md` — 베타 전 최종 확인 필요사항
- `LAUNCH_FINALIZATION.md` — Launch Finalization 준비. 체크리스트는 완료된 작업이 아님
