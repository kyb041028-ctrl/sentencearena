# 법적·운영 문서 검토용 초안

이 폴더의 문서는 **베타 공개 전 내부 검토용 초안**입니다.

- 사이트 화면에 연결하지 않았습니다.
- 가입 흐름, 체크박스, Production, 데이터 저장구조는 변경하지 않았습니다.
- 저장소에서 확인하지 못한 사업자 정보·연락처·서버 국가는 `[확인 필요]`로 남겨 두었습니다.

- `TERMS_DRAFT.md` — 이용약관 초안
- `PRIVACY_POLICY_DRAFT.md` — 개인정보처리방침 초안
