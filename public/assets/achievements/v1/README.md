## 실개발 통합 지시
1. 프로필 업적 목록은 93×71 PNG **한 장만 렌더링**할 것. 기존 빈 슬롯 93×71 자리에 교체한다.
2. 획득 연출 중앙 큰 카드는 930×710 이미지를 사용한다. 당장 자동 보상 로직을 새로 만들지 말고 현재 코드를 분석하고 기존 정책을 유지한다.
3. 확정한 연출 시간은 **6초 연출 + 3초 결과 유지 = 총 9초**다. 중앙의 큰 카드, 제목·설명·난이도 별 표시, 카드화·별 획득·업적 리스트 이동을 기존 디자인에 맞게 구현한다. 카드화·별 획득·리스트 이동의 소요시간은 서로 같게 구성한다.
4. 프로필 빈 슬롯·획득 슬롯 간 크기/위치 동일 여부, 데스크톱·모바일, 감소된 움직임 환경 설정을 검증한다.
5. 실제 Supabase 로그인/운영 인증은 검증하지 않았다. 실서버/실DB 변경 금지, 현 개발 브랜치의 미커밋 작업 보존, master 병합/push 금지.
